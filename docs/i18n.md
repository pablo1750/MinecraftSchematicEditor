# Traducción del editor: español (Argentina) e inglés

## Uso

La aplicación inicia en Español (AR). Se puede cambiar a English desde el selector de idioma en la barra superior. La preferencia se recuerda en el navegador mediante `localStorage`.

El idioma **solo afecta los textos visibles**; no cambia los estados de bloque, las claves de materiales, los comandos ni los datos escritos en archivos Minecraft.

## Nombres de bloques

- `src/i18n/blocks-es-ar.json` recoge exclusivamente las claves de bloques e ítems del catálogo de traducciones de Minecraft para `es_ar`. Fuente: espejo de archivos de idioma de Minecraft `xydesu/minecraft-lang` (rama de versiones estables, consultado 15/11/2026); el contenido pertenece a Mojang Studios / Microsoft.
- `displayName()` busca primero `block.minecraft.<id>`, luego `item.minecraft.<id>`.
- Los bloques de mods y entradas inexistentes en el catálogo conservan el nombre técnico humanizado, nunca se renombran internamente.
- La búsqueda de bloques acepta nombre español, texto inglés del ID y `minecraft:<id>`.
- Las propiedades de orientación se traducen únicamente al mostrarlas.

## Textos de interfaz

- Diccionario `src/i18n/ui-es.json` con etiquetas, ayudas y mensajes.
- Traducción reactiva centralizada: `src/i18n/index.ts`.
- `scripts/localization-plugin.mjs` sustituye textos JSX estáticos y atributos de presentación durante la compilación Vite. El código fuente no necesita cambiar sus claves técnicas ni su lógica.
- Se conservan textos en inglés para los que no exista entrada en el diccionario; es preferible mostrar el original a inventar traducciones de un comando o una propiedad.

Para completar una traducción, agregar el par `"Original English": "Traducción español"` a `ui-es.json`. La transformación solo afecta textos de interfaz claramente identificados. Para avisos generados en código, usar `translate(text)` en el punto de visualización.

## Pruebas y compilación

`node scripts/test-i18n.mjs` verifica catálogo y transformación JSX; GitHub Actions ejecuta esa prueba, TypeScript y Vite. La compilación se activa con el contador de `run_compiler.work` en `desarrollo` y crea un artifact por dos días.

No se modificó PHP ni ningún formato `.schem`, `.litematic` o `.nbt` como consecuencia de la traducción.
